# Sponsor integrations

Read [partner technologies](../../../docs/implementation.md#partner-technologies) for what the project uses. Start with the user problem and choose only a useful integration. Check current event eligibility and terms; preserve honest implementation and demo evidence. Do not install unused SDKs or provision hosted resources by default. Each cloud plan needs a person's approval. Entire is an explicit person-requested pilot only, with destination, secret, hook and current-client checks before capture. Never create cross-candidate memory.
